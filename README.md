Этот проект представляет собой чат-бот для обработки запросов клиентов банка (для примера был взят BNP Paribas), 
построенный на архитектуре Retrieval-Augmented Generation (RAG). 
Бот обеспечивает точные и контекстуализированные ответы на основе внутренней базы знаний, используя векторные вложения и семантический поиск.
Это снижает нагрузку с L1 - обрабатывает 60-70% стандартных вопросов и убирает простые тикеты из очереди L1, также даёт быстрый первичный ответ 24/7.
⚠️ Но все же требует человеческого контроля и эскалации как и любой LLM.
