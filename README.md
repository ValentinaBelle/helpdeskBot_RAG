Это пример чат-бота для обработки первичных запросов клиентов банка c RAG.
Бот предоставляет ответы на основе внутренней базы знаний с семантическим поиском, которые были "скормлены" ему.
Если не затупит и не заглючит, то может дать быстрый первичный ответ даже ночью и в лучше случае, сможет обработать 60-70% стандартных вопросов первой линии.
