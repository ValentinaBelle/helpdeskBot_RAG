Это чат-бот для обработки запросов клиентов банка c RAG. 
Бот обеспечивает контекстуализированные ответы на основе внутренней базы знаний с семантическим поиском.
Даёт быстрый первичный ответ 24/7 и обрабатывает 60-70% стандартных вопросов.
